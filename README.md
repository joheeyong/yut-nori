# 윷놀이 (Yut Nori)

한국 전통 보드게임 윷놀이 온라인 게임

## Tech Stack

- **Frontend (Web)**: React
- **Frontend (App)**: Flutter
- **Backend**: Spring Boot 3.4
- **Database**: MySQL
- **Infra**: AWS

## Project Structure

```
yut-nori/
├── client/   # React 웹 클라이언트
├── server/   # Spring Boot 서버
└── (flutter) # Flutter 앱 (추후 추가)
```

## Features

- AI 컴퓨터 대전
- 온라인 멀티플레이어 대전
